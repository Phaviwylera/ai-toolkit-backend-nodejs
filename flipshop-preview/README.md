# FlipShop — public interactive DEMO

This is an original Flipkart-inspired shopping storefront demo. It is **not affiliated** with Flipkart and has **no real orders, payments, delivery, login, or inventory**.

Published as a static site from the isolated `flipshop-public-preview` branch of `Phaviwylera/ai-toolkit-backend-nodejs`, in folder `flipshop-preview`. All other production branches remain unchanged.

The app includes browse/search/sort, product details, category selection, wishlist, cart with quantity management, fake checkout, and demo orders. State is stored in sessionStorage in the current browser tab. No personal data collection. Single-page standalone HTML. Deploy as static site with build command `echo flipshop-static-ready` and publish path `flipshop-preview`.
